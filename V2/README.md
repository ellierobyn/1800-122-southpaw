# 1800-122 Southpaw V2
This version of the board is the actively in development version using local repos and generally better best practices.

NOTE: The key switch used in the 122-LIB "SW_Hotswap_Kailh_MX_1.00u_PnP" forked from the official KiCad key switch repo is identical in all ways **EXCEPT** its component origin is located at the centroid of the physical hotswap socket so the .pos file exported is compatible with Pick and Place machines for automated PCB assembly.
