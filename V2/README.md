# 1800-122 Southpaw V2
This version of the board is the actively in development version using local repos and generally better best practices.

NOTE: The footprint used in the 122-LIB "SW_Hotswap_Kailh_MX_1.00u_**PnP**" forked from the official KiCad key switch repo is identical in all ways to "SW_Hotswap_Kailh_MX_1.00u" **EXCEPT** its component origin is located at the centroid of the physical hotswap socket so the .pos file exported is compatible with Pick and Place machines for automated PCB assembly.
